# Encore: The Last Dance

An original Undertale-inspired bullet-hell boss encounter featuring The Showman.

## Run locally

Open `index.html` in a modern browser. Keep `style.css`, `game.js`, and `assets/battle.ttf` together.

## Controls

- Move: WASD or arrow keys
- Strike: Space
- Pause: P
- Touch: drag the heart inside the battle box

## Project workflow

GitHub is the source of truth. Vercel can deploy the root of this repository as a static site after the game files are added and tested.

## Note on assets

The recovered source archive currently includes the battle font but may not contain all original Showman artwork. Verify visuals against the original game before replacing the original hosted version.
