LAST ENCORE — The Showman

Run locally: open index.html in a modern browser. Keep style.css, game.js, and assets/battle.ttf together.

Changes in this repair:
- Removed the implicit low-health mercy tone; HP can reach zero and triggers a death sequence.
- Added a black-screen opening with a heart, battle-box reveal, and short synthesized intro tones.
- Added the upside-down heart and pixel-shatter defeat animation before GAME OVER.
- Added Hard (default), Normal, and Easy difficulty settings. Rehearsal mode remains as an extra-gentle option.
- Increased light-beam damage and tightened hard-mode attack timing/projectile patterns.
- Added a ninth act, THE SHADOW COMPANY: three shadow actors attack while the Showman watches from the background.

Controls: WASD / arrow keys to move; Space to strike; P to pause; touch users can drag the heart.
